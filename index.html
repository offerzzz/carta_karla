👨‍🏫 Profesor Shin-chan explica circuitos

🔗 Circuito en Serie

Las resistencias están una tras otra, formando un solo camino para la corriente. Todas comparten la misma corriente (I), pero cada una tiene su propia caída de voltaje.

  • Resistencia total: R_T = R1 + R2 + R3 + ...
  • Corriente: I es igual en todo el circuito
  • Voltaje: V_T = V1 + V2 + V3 + ...
  • Si una resistencia se daña o se abre, ¡todo el circuito deja de funcionar! (como una fila de foquitos de navidad)

🪜 Circuito en Paralelo

Las resistencias están cada una en su propia rama, todas conectadas entre los dos mismos puntos (nodos). Todas comparten el mismo voltaje (V), pero la corriente se reparte entre las ramas.

  • Resistencia total: 1/R_T = 1/R1 + 1/R2 + 1/R3 + ...
  • Voltaje: V es igual en cada rama
  • Corriente: I_T = I1 + I2 + I3 + ...
  • Si una rama se daña, las demás siguen funcionando (como los focos de tu casa)

🧩 Circuito Mixto

Combina partes en serie y partes en paralelo dentro del mismo circuito. Para resolverlo:

  1. Identifica primero los grupos en paralelo (como R2 y R3) y calcula su resistencia equivalente.
  2. Ese resultado ahora se trata como una sola resistencia en serie con las demás (R1 y R4).
  3. Suma todo como en un circuito en serie para obtener R_T.
  4. Luego usa la Ley de Ohm (V = I × R) para hallar corrientes y voltajes de cada parte, trabajando "de afuera hacia adentro".

💡 Truco de Shin-chan: simplifica el circuito por partes, como si fueras armando un Kamen Rider por piezas, ¡hasta que quede una sola resistencia!
