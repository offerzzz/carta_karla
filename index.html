1. Circuito en Serie 🔌
Un único camino continuo para la corriente eléctrica.
• Corriente: I_total = I1 = I2 = I3
• Voltaje: V_total = V1 + V2 + V3
• Resistencia: R_eq = R1 + R2 + R3
2. Circuito en Paralelo 🔀
Múltiples caminos donde todos los elementos reciben el mismo voltaje.
• Voltaje: V_total = V1 = V2 = V3
• Corriente: I_total = I1 + I2 + I3
• Resistencia: 1/R_eq = 1/R1 + 1/R2 + 1/R3
3. Circuito Mixto 🧩
Combina conexiones en serie y paralelo en una misma red eléctrica.
• Estrategia: Reducir primero las ramas en paralelo y luego sumar las resistencias en serie.
