1. Circuito en Serie (Malla Única)
Existe un único camino para la corriente. La intensidad (I) es exactamente igual en todos los elementos.
• Corriente: Itotal = I1 = I2 = ... = In
• Voltaje (LKV): Vtotal = V1 + V2 + ... + Vn
• Resistencia equivalente: Req = R1 + R2 + ... + Rn
• Divisor de Tensión: Vx = Vtotal · (Rx / Req)
👉
2. Circuito en Paralelo (Nodos Comunes)
Los terminales se conectan a dos puntos comunes. Todos los componentes tienen el mismo voltaje (V).
• Voltaje: Vtotal = V1 = V2 = ... = Vn
• Corriente (LKC): Itotal = I1 + I2 + ... + In
• Resistencia eq: 1/Req = 1/R1 + 1/R2 + ... + 1/Rn
• Fórmula para 2 resistencias: Req = (R1 · R2) / (R1 + R2)
• Divisor de Corriente: I1 = Itotal · [R2 / (R1 + R2)]
👉
3. Circuito Mixto
Combinación de serie y paralelo en una sola red. Se resuelve reduciendo partes paso a paso.
• Paso 1: Identificar qué ramas están estrictamente en serie o en paralelo.
• Paso 2: Reducir los bloques internos a resistencias equivalentes parciales.
• Paso 3: Aplicar Ley de Ohm (V = I · R) en el circuito simplificado total.
